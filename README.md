# Nitin Thakare | Career Guidance & Educational Counselling

Personal brand website for career guidance and educational counselling. This is a static single-page site with no build step.

## Live site

https://nitinrthakare.github.io/Educated_website/

## Files

- `index.html` contains the website and contact/enquiry form.
- `robots.txt` and `sitemap.xml` use the GitHub Pages URL above.
- `netlify.toml` is retained from the original archive; GitHub Pages does not use it.

## Hosting

GitHub Pages is configured to publish the `main` branch from the repository root. Adding or updating the root `index.html` publishes the site.

## Enquiries and email

The site lists `ratanrthakare@gmail.com` and includes a mailto fallback for visitors. GitHub Pages is static hosting and does not deliver form submissions to an inbox automatically. To enable automatic form delivery, set a Formspree endpoint in `CFG.formspree` in `index.html`; until then, a visitor must use the email link and send the prefilled message from their own email app.
